This release adds run lengths to chart downloads: the number of stitches in each run of one colour along a row. Row counts in a download can now also be numbered from the top, for knitting from the top down.

  ### Added
  - "Show run lengths" in the download dialog writes the number of stitches on each run of one colour along a row, for runs of 5 or more stitches or any length you choose
  - Row counts in a download can be numbered from the top, for knitting top down

  ### Dependencies
  - Routine updates from Dependabot
